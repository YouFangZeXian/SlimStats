# Upstream reference

SlimStats uses the open source [Stats](https://github.com/exelban/stats) project as a reference for the menu bar presentation and memory terminology. The implementation in this directory is a small AppKit app with only memory and storage collection enabled. It does not embed Stats modules or third-party dependencies.

Stats is licensed under the MIT License. This project does not copy source files from Stats; the system collection APIs and the UI behavior are implemented locally from the requirements document.
